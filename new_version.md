# TremDeGravarOsTrem 0.0.1

O trem que grava os trem da sua tela. Gravador grátis e open-source para Windows.

## Baixar

- **GravaTrem-Setup-0.0.1.exe** (anexo abaixo) — instalação por usuário, sem admin.

## Destaques

- Tema claro moderno (Poppins + FontAwesome) com preview ao vivo durante a gravação
- Tela, janela ou região + foto PNG (F11)
- Pausar/retomar com a pausa cortada do MP4 — trio REC / Pausar / Parar
- Áudio multitrilha estilo OBS (mix + mic + sistema isolados)
- Mixer ao vivo (VU, dB, osciloscópio), painel de gravações e aba de logs
- Pasta de saída configurável (`Documentos\TremDeGravarOsTrem`)
- MP4 H.264 + AAC que roda em tudo

## Requisitos

- Windows 10/11 64-bit
- Áudio do sistema exige dispositivo com loopback WASAPI
- Microfone opcional
